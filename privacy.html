Privacy Policy

Cardsheet for Trello · Last updated 23 September 2026

Cardsheet is a Trello Power-Up that renders the cards of a board as sortable, filterable tables. This policy describes exactly what the Power-Up does with data. The short version: it has no server of its own, so there is nowhere for your data to be sent.

No backend, no account

Cardsheet is a set of static files (HTML, CSS and JavaScript) served over HTTPS. All of its logic runs inside your own browser, in the iframe that Trello provides. There is no application server, no database, no user account and no login. The Power-Up does not ask for, receive or store a Trello API token.

What board data it reads

To draw the table, the Power-Up asks Trello's own client library for the data of the board you are currently viewing:

  • list names and identifiers;
  • card name, card number, list, due date and completion state;
  • card labels and their colors;
  • the display name or username of members assigned to a card.

This data is held in the browser's memory only for as long as the table is open, and is used solely to render what you see on screen. It is never transmitted to the author of this Power-Up, and never to any third party. Closing the table discards it.

What it writes

Cardsheet never modifies your cards, lists or boards. It does not create, edit, move, archive or delete anything in Trello.

The only thing it saves is your own display preferences: which columns and lists are visible, the sort order, and whether rows are grouped by list. These are stored through Trello's own storage API, using t.set('board', 'private', ...). That means they are kept on Trello's infrastructure, scoped to a single board and visible only to your own member account. They never leave Trello, and the author of this Power-Up cannot read them.

The Power-Up deliberately does not use cookies, localStorage, sessionStorage or IndexedDB.

No tracking

There is no analytics, no telemetry, no advertising, no fingerprinting and no third-party tracking script of any kind. No profile of you is built and no data about you is ever sold, rented or shared.

Hosting and network requests

The static files are hosted on GitHub Pages. Like any web host, GitHub serves those files in response to a request from your browser and may record standard technical request data, such as an IP address, in its own server logs. That processing is governed by GitHub's Privacy Statement, and the author of this Power-Up has no access to those logs.

The Power-Up also loads Trello's own client library and stylesheet from p.trellocdn.com, which is required for any Power-Up to function and is governed by Atlassian's Privacy Policy. No other external request is made.

Removing your data

Because the only stored data is the preference record held inside Trello, disabling the Power-Up on a board removes the Power-Up's access to it. No copy exists anywhere else for the author to delete.

Source code

Cardsheet is open source. Every claim on this page can be verified by reading the code at github.com/miljavi96/trello-table-view.

Changes to this policy

If the Power-Up ever begins handling data differently, this page will be updated and the date at the top will change.
